Scalable watermarking for identifying large language model outputs

Nature Vol 634, 24 October 2024

Plate 01 / Hero

A watermark you cannot see, at the scale of Gemini

SynthID-Text is a production-ready text watermarking scheme that preserves text quality, enables high detection accuracy, and adds minimal latency.

It does not change LLM training. It only changes sampling. Detection does not need the underlying LLM.

Plate 03 / Prior ideas

Three other ideas, and why they struggle

  1. Keep a growing record

    Store every generated text and search it later. Privacy, scale, and coordination get in the way.

  2. Train a classifier after the fact

    Expensive. Inconsistent. Biased against some groups such as non-native speakers. It decays as models improve.

  3. Edit-based or data-driven marks

    Synonym swaps, Unicode tricks, trigger phrases. They can leave artefacts.

Plate 04 / Method

How SynthID-Text works

Autoregressive LLMs pick the next token from a probability distribution. SynthID-Text biases that sampling with a secret key.

Tournament sampling, in one breath: sample several candidate tokens, play knockout matches using pseudorandom g-values, and the winner is the next token.

Hold this in one breath

  1. Sample several candidate tokens from the next-token distribution.
  2. Pair them. Knockout matches use pseudorandom g-values from the key.
  3. Winners play the next layer. Experiments generally use m = 30 layers, stacking more watermark evidence per token.
  4. The last winner is the token the model writes.
  5. Detection scores the finished text against the same key. Longer text and higher entropy make detection easier.

Plate 05 / Quality

Quality, at the scale of Gemini

Live Gemini experiment: about 20 million watermarked and unwatermarked responses.

0.01%

Thumbs-up rates differed by this amount. Watermarked was higher.

0.02%

Thumbs-down rates differed by this amount. Watermarked was lower.

n.s.

Both differences were statistically insignificant, inside 95% confidence intervals.

Also a side-by-side human test: Gemma 7B-IT answers to 3,000 ELI5 questions. Five aspects: grammaticality/coherence, relevance, correctness, helpfulness, overall. No significant rater preference.

Production config

Non-distortionary

Two competitors per match, plus repeated context masking. This is the production config.

Stronger mark

Distortionary

More competitors per match. Trades some quality for a stronger mark.

Plate 06 / Speed

Speed, with speculative sampling

Production systems use speculative sampling. A small draft model proposes tokens. The large model accepts or rejects them.

Combination A

High-detectability

Watermarked speculative sampling that keeps the mark strong.

Combination B

Fast

Keeps draft speed if the watermark is single-token non-distortionary. Use this when latency matters.

SynthID-Text has been productionized in Gemini and Gemini Advanced.

Plate 07 / Detection

Detection does not run the LLM

Scoring does not run the LLM. It measures the text against the same secret key used at sampling time.

The main chart metric is true-positive rate at 1% false-positive rate.

  • Non-distortionary SynthID-Text beats Gumbel sampling.
  • Distortionary SynthID-Text beats Soft Red List at the same perplexity cost.
  • A selective predictor can abstain when unsure, to hold TPR 95% / FPR 1%.

Plate 08 / Limits

Limits

  • Needs the generating service to apply the mark.
  • Open-source models and other labs are not covered.
  • Vulnerable to stealing, spoofing, scrubbing, and paraphrasing. Edits weaken it.
  • Complementary to post-hoc detectors, not a replacement.
  • Consistent across languages in their tests, unlike many classifiers.
